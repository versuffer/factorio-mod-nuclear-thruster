## Nuclear Thruster

Adds balanced late-game thruster that uses Uranium thruster fuel and water to operate. It has modified efficiency curve and significantly more thrust. Nuclear Thruster can be unlocked before Aquilo. You can also make Nuclear thruster symmetric and increase Uranium thruster fuel fuel_value to get more thrust. This mod also adds an alternative way to get uranium in space - metallic asteroid uranium extraction.

## New technologies

-   Nuclear Thruster, unlocks after:
    -   Metallurgic science pack;
    -   Electromagnetic science pack;
    -   Carbon fiber;
    -   Nuclear power;
-   Uranium thruster fuel from waste, unlocks after:
    -   Nuclear Thruster;
    -   Nuclear fuel reprocessing;

## New fluids

-   Uranium thruster fuel:
    -   Produced from Uranium-235, Uranium-238 and water;
    -   Has 850 kJ fuel_value (original thruster fuel has 50 kJ fuel_value);

## New entities

-   Nuclear Thruster:
    -   Intended to be played in late-game;
    -   Production is expensive;
    -   Uses Uranium thruster fuel and water to operate;
    -   Uranium thruster fuel is expensive and cannot be barreled;
    -   Min efficiency: 1%;
    -   Max filling efficiency: 97%;
    -   Max fuel consumption: 100% (60 units/s each of fuel and water);
    -   Fuel storage volume (fuel and water): 1.0k;
    -   Max thrust: 49.5 GN (~8x vanilla thruster);

## Additional features

-   Metallic asteroid uranium extraction: alternative way to get uranium ore in space, uranium ore probability can be adjusted in settings;
-   Nuclear thruster fluid boxes can be set symmetrical for more convenience (see "Enable Nuclear thruster fluid box symmetry" in settings);
-   You can choose between two flame effect graphic styles (see "Enable Nuclear thruster alternative flame graphics" in settings);
-   Uranium thruster fuel fuel_value can be adjusted. It allows to get more thrust from the same amount of fuel burned (BE CAREFUL WHEN ADJUSTING!);

## Existing saves

-   Mod changes:
    -   Adds fluid boxes to original Centrifuge;
    -   Adds custom recycling recipe for Nuclear Thruster;
-   Mod does not change vanilla entity or item properties except ones described over. Mod is mostly safe for using with existing save but it is ***STRONGLY RECOMMENDED*** to make backup before installing ***OR*** updating mod version (new major versions contain changes that break backward compatibility);
